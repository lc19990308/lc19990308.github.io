# LewChaw 主页改版 · 第二轮

2026-10-28。本地候选版本，保留三维驿站首屏，尚未提交或发布。

## 本轮更新

- 增加独立 Loading 页面，按真实的资源加载、场景构建、画面准备阶段更新。首帧提交后自动进入；支持“先看主页”、Escape 和超时退出。直接访问项目等锚点时绕过 Loading。
- 引擎与几何工具并行预取；场景分段构建，让加载界面能够更新；提前异步准备着色器，减少重复初始绘制。
- 玻璃改用轻量透明材质，保留工作室轮廓与玻璃外观，取消额外透射渲染。继续合并静态零件，保留人物和设备运动。
- 取消 1240px 宽度上限。大屏左右各留约 3.5% 边距，放大驿站与标题，项目改为交错画廊，写作和联系区采用分栏。正文限制行长。
- 加载失败时保留静态预览，可重新连接。后台、离屏和手动暂停继续停止持续动画；修复后台初始化与减少动态效果组合下的空白首帧问题。

## 验证结果

同一台电脑、同一浏览器、相同 1265px 页面内容视口，使用同一新版首页交替加载优化前后的场景，各三次，无网络限速，HTTP 响应为 no-store：

| 指标 | 优化前 | 本轮 |
| --- | --- | --- |
| iframe 启动到父页面收到 ready | 481 / 456 / 381ms | 331 / 343 / 351ms |
| 启动中位数 | 456ms | 343ms |
| 首帧绘制调用 | 496 | 328 |

本机启动中位数减少约 25%，绘制调用减少约 34%。启动时间包含资源获取、构建、着色器与首帧提交，不代表画面实际呈现时间、线上网络表现或 Core Web Vitals。浏览器及 GPU 缓存不受本次测试控制。原始记录见 docs/performance-samples.json。

已在实际浏览器验证：

- 1920×1080、2560×1440、390×844 的真实 iframe 布局视口均无横向溢出；大屏宽度随视口增加，手机继续先展示驿站。
- Loading 阶段更新、主动跳过和加载完成后自动退出。
- 本地注入加载失败后，静态预览和重试入口可用；重试恢复真实场景。
- 项目锚点直达不显示 Loading，且未设置离屏 3D 的 src。
- 暂停按钮切换到静态状态，播放可恢复；浏览器正常页面无控制台错误。

自动验证覆盖静态合并的变换/边界与排除条件、后台首帧、减少动态效果、暂停及可见性生命周期、Loading 的跳过/完成/超时。语法检查与独立代码审查通过。

没有进行真实手机触摸、系统级减少动态效果模拟、国内多地区网络、Lighthouse 或 Core Web Vitals 测量。

## 预览与发布

原生 HTML/CSS/JS 静态站，无需 npm 安装或构建。ES Modules 需要 HTTP 服务，不能直接双击 index.html。

安装了 Python 时，可在此目录执行：

    python -m http.server 8000

然后访问 localhost:8000。当前会话另有 localhost:4173 预览。

发布时将本目录内容放入 GitHub Pages 站点根目录，并保留原仓库其他内容。博客、作品集与 PDF 链接仍使用现有线上地址，本包不包含这些独立站点。

所有运行资源同源，无 Google Fonts 等远程运行依赖。Three.js 与 BufferGeometryUtils 为 r180，许可证位于 vendor/THREE-LICENSE。
